# Security policy

## Reporting a vulnerability

**Do not report security vulnerabilities in public GitHub Issues.**

Prefer [GitHub Private Vulnerability Reporting](https://github.com/rezamxs/MonitoringXS/security/advisories/new) when available. If private reporting is not yet enabled for this repository, contact the maintainer through the repository's GitHub profile.

### What to include

- Affected Monitoring XS version or commit
- Windows version and build
- Step-by-step reproduction instructions
- Impact assessment
- Sanitized logs or screenshots if relevant

### What not to include

Never attach passwords, credentials, access tokens, private file paths, command lines containing sensitive arguments, or unredacted network destinations. Remove all sensitive data before sharing any diagnostic output.

## Process

Maintainers will acknowledge a complete report, investigate promptly, coordinate a fix, and credit reporters who want attribution.

## Supported versions

The current development branch is supported. Security updates are published through GitHub Releases once releases begin.
