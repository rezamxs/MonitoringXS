# Security policy

Please do not disclose vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository. Include the affected revision, Windows build, reproduction steps, impact, and a minimal sanitized diagnostic trace.

Never attach command lines, credentials, access tokens, private paths, or unredacted network destinations. Maintainers will acknowledge a complete report, investigate, coordinate a fix, and credit reporters who want attribution.

The current development branch is supported. Security updates are published through GitHub Releases once releases begin.
